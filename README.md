# Hyderabad Hardware Experience Centre

A premium, interactive digital experience for Hyderabad Hardware, showcasing world-class architectural fittings, kitchen solutions, and luxury wardrobes.

This web application serves as a high-end digital storefront and interactive portfolio showcasing our exclusive partnerships with international brands like **Blum** (Austrian kitchen hardware) and **Astronea** (Italian wardrobe systems).

---

## 🚀 Development & Setup

Follow these steps to run the project locally:

### 1. Install Dependencies
```sh
npm install
```

### 2. Run the Development Server
```sh
npm run dev
```

### 3. Build for Production
```sh
npm run build
```

### 4. Local Production Preview
```sh
npm run preview
```
