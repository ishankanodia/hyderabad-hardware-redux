# Hyderabad Hardware Experience Centre

A premium, interactive digital experience for Hyderabad Hardware, showcasing world-class architectural fittings, kitchen solutions, and luxury wardrobes.

This web application serves as a high-end digital storefront and interactive portfolio showcasing our exclusive partnerships with international brands like **Blum** (Austrian kitchen hardware) and **Astronea** (Italian wardrobe systems).

---

## 🌟 Interactive Features

The site features three bespoke, highly interactive digital showroom simulators:

1. **Blueprint Floor Explorer (Homepage)**: A grid-aligned, vector-style architectural blueprint mapping the Ground Floor, First Floor, and Third Floor showrooms. Visitors can hover over locations and click pulsing hotspot pins to explore specific showrooms.
2. **Motion & Soft-Close Simulator (Blum Page)**: A physics-based movement simulator demonstrating:
   - **Aventos HF**: Dynamic bi-fold lift cabinet doors that swing up and fold overhead.
   - **Tip-On**: Click-to-release spring-loaded drawer systems.
   - **Blumotion Soft-Close**: A drag-and-release drawer runner with a dedicated "Slam Drawer" damping animation that simulates hydraulic impact absorption.
3. **Slim-Frame Profile Visualizer (Astronea Page)**: An interactive 3D-style wardrobe configurator allowing real-time selection of:
   - **Aluminum Frames**: Nero Matt, Oro Brass, Bronzo Matte, and Champagne Gold.
   - **Glass Panels**: Vetro Chiaro (Clear), Vetro Fumé (Smoked), Vetro Bronzo (Bronze), and Vetro Cannettato (Fluted/Ribbed glass).
   - **Lighting**: Toggleable internal vertical LED strips.
   - **Sliding Action**: Tap to slide the glass door open/close to reveal interior wardrobe details.

## 🛠️ Technology Stack

- **Framework**: React 18 (with TypeScript)
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS & custom CSS variables
- **Animations**: Framer Motion & Lucide Icons

## 🚀 Development & Setup

Follow these steps to run the project locally:

### 1. Install Dependencies
```sh
npm install
```

### 2. Run the Development Server
```sh
npm run dev
```

### 3. Build for Production
```sh
npm run build
```

### 4. Local Production Preview
```sh
npm run preview
```
